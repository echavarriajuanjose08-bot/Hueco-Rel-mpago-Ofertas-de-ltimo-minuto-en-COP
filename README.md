# Hueco Relámpago

Aplicación web estructurada por carpetas para publicar y reservar espacios de último minuto con descenso de precio configurable en pesos colombianos (COP).

## Estructura del proyecto
- `index.html`: Listado de huecos activos, búsqueda, filtros y reserva inmediata.
- `pages/publicar.html`: Formulario para que cada profesional publique su servicio y defina precio inicial, mínimo, intervalo en minutos y monto de bajada.
- `pages/mis-reservas.html`: Consulta de reservas confirmadas.
- `assets/css/styles.css`: Estilos y fondos por vista.
- `assets/js/`: Motor de cálculo, almacenamiento y renderizado de interfaz.
- `assets/img/`: Imágenes de fondo para cada vista (`bg-inicio.jpg`, `bg-publicar.jpg`, `bg-reservas.jpg`).
